사람의 수정이 다음 장면의 번역 후보로 이어지는가

저작권 없는 자체 샘플과 고정 번역후보만 사용합니다. 이 데모는 OCR이나 실제 LLM 번역이 완성된 것처럼 보이기 위한 화면이 아니라, candidate → human edit → approved memory → next-scene reuse라는 제품 가설을 직접 클릭해보는 데 목적이 있습니다.
